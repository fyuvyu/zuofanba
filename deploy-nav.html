Render 部署步骤 照着点，全程不用绑卡

  1. 点上面「① 注册 Render」直接用 GitHub 账号登录最快，不用单独填资料。
  2. 把项目传到 GitHub新建一个空仓库，把 做饭吧App v5 里的文件推上去。项目自带 .gitignore，会自动排除 data/db.json 和用户上传的图片。
  3. 点「② 新建 Web Service」，选你的仓库 → Connect可能会先让你授权 Render 读取 GitHub 仓库，点同意即可。
  4. 照这张表填 Name：zuofanba（决定网址前缀）
    Language：Node
    Build Command：npm install
    Start Command：npm start
    Instance Type：Free ← 千万别选错，选错就要钱
  5. 点 Deploy Web Service，等状态变 Live首次构建约 2–4 分钟。
  6. 复制页面顶部的网址形如 https://zuofanba-xxxx.onrender.com，这就是你要的、能直接点开的链接。手机打开后「添加到主屏幕」就变成 App 图标。
不想用 GitHub？也可以用 Docker 部署：仓库里已经有 Dockerfile，创建服务时 Language 选 Docker，其余全部留空即可。

必须知道的三个限制

1. 会休眠。15 分钟没人访问就睡，下次打开要等约 1 分钟（会显示加载页）。
2. 数据会丢。免费实例的磁盘是临时的，重新部署 / 重启 / 休眠唤醒都会清空 data/db.json 和上传的图片。免费档不支持挂持久磁盘（那是付费功能）。
3. 每月 750 小时。整月 24 小时不停约需 720 小时，几乎吃满。所以别用定时 ping 硬撑着不休眠，会超额度。

MongoDB Atlas 接入 已写进代码，填个环境变量就行

代码已经接好了，不用改一行代码：配上 MONGODB_URI 就走云端，不配就还是本地文件。 连不上也会自动回退，不会让网站打不开。

注册 MongoDB Atlas（免费 M0）→ 控制台 →
  1. 注册并创建集群选 M0 Free（512MB 永久免费），区域选 Singapore 或 Hong Kong，延迟更低。
  2. Network Access 放行加 0.0.0.0/0。免费托管平台出口 IP 不固定，只能全放开，安全性靠强密码。
  3. Database Access 建用户用密码认证，点 Autogenerate 生成强密码并保存好。
  4. 复制连接串Connect → Drivers，形如 mongodb+srv://user:pass@cluster0.xxx.mongodb.net/，密码里的特殊字符要 URL 编码。
  5. 填进托管平台的环境变量MONGODB_URI = 连接串。可选：MONGODB_DB（默认 zuofanba）、MONGODB_COLLECTION（默认 appstate）。
  6. 看启动日志确认出现 [store] MongoDB 已连接 就成功了；出现「回退本地 JSON」说明连接有问题。
数据怎么存的？整份业务数据作为一个文档存在 zuofanba.appstate 里（_id: "singleton"）， 写入做了 120ms 防抖合并。好处是 30 多个接口一行都不用改；家务级数据量完全够用。 详细说明见同目录 MONGODB.md。

零注册方案 跑自己电脑上，完全免费

如果你只是家里人用、不想注册任何平台：装好 Node.js 18+，在项目目录执行 npm start，本机打开 http://localhost:3000； 手机连同一个 WiFi，访问 http://你电脑IP:3000 就行。 想临时让外网也能进，在电脑上跑 cloudflared tunnel --url http://localhost:3000， 会给你一个 https://xxx.trycloudflare.com 的临时地址（电脑关了就没）。
