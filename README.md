# 做饭吧 v4 · 联网版（真实后端）

> 这次是**真联网**：不再是复制粘贴传码。绑定后，家人点菜你手机直接收到；共享菜单、美食广场、关注粉丝都是真实服务器数据。

## 一、怎么跑起来（选一种）

### 方式 A：自己电脑跑（最简单，3 分钟）
需要装 Node.js（18 以上）。装好后打开终端，进到本文件夹：

```bash
node server.js
```

看到 `做饭吧 v4 已启动: http://localhost:3000` 就成了。
浏览器打开 **http://localhost:3000** 就能注册。

> 数据存在本文件夹 `data/db.json` 里，升级/搬家把这个文件一起带走就行。

### 方式 B：手机也一起用（同一个 WiFi）
1. 电脑终端跑 `node server.js`
2. 查电脑内网 IP：
   - Windows：`ipconfig` → 看「IPv4 地址」，如 `192.168.1.8`
   - Mac / Linux：`ifconfig | grep 192.168`
3. 手机浏览器打开 `http://192.168.1.8:3000`
4. 手机点「添加到主屏幕」，就是个 App 了

这样你和你家人在同一个 WiFi 下都能用，互相点菜立刻收到。

### 方式 C：想让外网也能用（出门在外、不同网络）
在你**自己的电脑**上再开一个终端，装一个免费隧道（二选一）：

```bash
# 方法 1：cloudflared（推荐，稳定）
# 先装：https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
cloudflared tunnel --url http://localhost:3000
# 它会打印一个 https://xxx.trycloudflare.com 地址，这个地址外网可访问
```

```bash
# 方法 2：ngrok
npm i -g ngrok
ngrok http 3000
```

拿到 `https://xxx` 地址后，用手机打开、添加到主屏幕即可。把这个地址发给家人，他们也能注册登录。

> ⚠️ 免费隧道地址每次重启会变。想固定地址，就买个便宜 VPS（阿里云/腾讯云学生机几十块一年），把本文件夹传上去 `node server.js` 长期跑着，再绑个域名。

## 二、这次做的 6 件事（逐条对应你的要求）

### 1. 改成自行请求网络 ✅
所有数据走 HTTP 接口，存服务器 `data/db.json`。换手机登录同一账号，数据全在。
前端每 8 秒自动同步一次；切回 App 时立刻同步 —— **对方点了菜，你手机上会自己冒出来**。

### 2. 绑定双方直接收到点菜单（不用复制粘贴）✅
- 你选菜 → 选接收人（家人 / 自己）→ 发出
- 对方「待做」页立刻出现这单，底部导航带红点数字
- 对方点「开始做」→「做好了」→ 写一句回话
- 你手机上马上看到状态变化和回话

**整个过程零复制粘贴。**

### 3. 绑定验证码：随机 6 位 + 5 分钟有效 ✅
- 点「绑定家人」，系统生成一个**随机 6 位数字**（不是手机号后几位了）
- 屏幕上倒计时 `剩余 4:58`，5 分钟过期
- 过期后点「换一个」重新生成
- **一次性**：用过就失效，防重放
- 不能绑定自己；已绑定的不能再绑
- 关系可选：家人 / 情侣 / 朋友 / 室友 / 同事

> 为什么不用扫码？因为扫码在不同手机、不同浏览器兼容性很差（iOS Safari 不开放摄像头 API），随机 6 位数字念一遍就行，反而更快更稳。你要真想加扫码，代码里留了位置，告诉我我再补。

### 4. 共享菜单：可分组、可自建菜、不同人看到不同 ✅
- **自己命名**：随便起，比如「周末大餐」「妈妈爱吃的」「减脂餐」
- **选图标**：8 种
- **加菜两种方式**：
  - 从 83 道菜谱库加（带食材和步骤）
  - **写我自己的**：菜名 + 食材（一行一样）+ 做法（一行一步）+ 小提示
- **共享控制**：建菜单时勾选共享给谁，或之后在「共享设置」里随时改
- **不同关联人看到不同菜单**：
  - 「周末大餐」共享给阿珍 → 阿珍能看到
  - 「我的减脂餐」不共享 → 只有你自己能看到
  - 阿珍看不到、也改不了你的菜单（非创建者只读）

### 5. 美食广场 ✅
- **发布**：菜名 + 说说 + 做法步骤 + 最多 4 张照片（自动压缩到 1000px，省流量）
- **其他注册用户都能看到**（不需要绑定、不需要关注）
- **点赞**：❤️ 点亮/取消，计数实时
- **评论**：写在下面，带昵称头像
- **收藏**：⭐ 收藏后进「收藏」栏
- 四个分栏：最新 / 关注 / 收藏 / 我的
- 只能删自己的内容

### 6. 关注 / 粉丝（与绑定完全独立）✅
- 点作者的「＋关注」即可关注
- 「我的」页看粉丝数 / 关注数，点进去是三栏：**关注 / 粉丝 / 推荐**
- **粉丝**里能看到谁关注了你，一键「回关」
- 双方都关注 → 显示「**互相关注**」
- 推荐栏：按粉丝数推荐你还未关注的人
- 点用户头像 → 看 TA 的主页和作品
- **关键区分**：
  - **绑定** = 能互相点菜（私密关系，上限是你家人）
  - **关注** = 能看 TA 的美食内容（公开，可以关注任何人，互关也不等于绑定）

## 四、技术说明（给自己看）

```
server.js          后端，零第三方依赖，只用 Node 内置模块
public/index.html  页面骨架
public/app1.js     前端上半：网络层/登录/首页/点菜/待做/订单卡片
public/app2.js     前端下半：共享菜单/广场/关注粉丝/我的/外观
public/styles.css  样式（9 主题 + 12 背景 + 响应式）
data/db.json       所有业务数据（用户/绑定/订单/菜单/帖子）
data/recipes.json  83 道菜谱（只读库）
public/uploads/    用户上传的美食照片
test-e2e.js        后端全链路测试（60+ 断言）
```

- 密码：`scrypt` + 每用户独立盐，不存明文
- 会话：随机 32 字节 token，存 `data/tokens`
- 绑定码：`crypto.randomInt` 生成，5 分钟过期，用后即删
- 图片：前端 canvas 压到 1000px / 质量 0.78 再上传，单张上限 3.5MB
- 端口：默认 3000，可用 `PORT=8080 node server.js` 改

### 跑测试

```bash
node test-e2e.js        # 跑后端 60+ 断言
```

## 六、已知限制（说清楚）

1. **我没有给你一个在线网址**。这台沙箱机器没有稳定的公网出口，试了几种免费隧道都被掐断或截断响应。所以给你的是**完整可运行项目**，你在自己电脑上 `node server.js` 就能用，或者按上面方式 C 开个隧道让家人访问。
2. **数据存 JSON 文件**，适合家庭几个人用（几百用户没问题）。真要上千人，得换 SQLite/Postgres。
3. **同步是轮询**（8 秒一次），不是 WebSocket 推送。所以对方下单后，你手机最多 8 秒后自动出现；切回 App 会立刻同步。想要秒级可以加 WebSocket，代码结构支持。
4. **照片存在服务器磁盘**，备份要连 `public/uploads` 一起备份。
5. **没有做「忘记密码」**（需要短信服务）。目前只能改密码，忘了要靠管理员改 db。需要的话可以加邮箱重置。
6. **绑定不做扫码**，用随机 6 位数字（原因上面说了）。
